# 🪐 Esmelealem Exoplanet Catalogue: HWO Solar Neighborhood

**Live Interactive App:** [Launch the Exoplanet Catalogue on Streamlit](https://streamlit.app)

## About This Catalogue
This interactive exoplanet catalogue characterizes exoplanets existing within **80 light-years of our Sun**. Its primary purpose is to evaluate planetary properties and predict prime target exoplanets for future direct-imaging observations by **NASA's Habitable Worlds Observatory (HWO)**.

## Key Features
* **Solar Neighborhood Scope:** Filters and analyzes confirmed exoplanets located within 80 light-years of Earth.
* **HWO Target Prediction:** Highlights top candidate worlds based on habitability and observability criteria.
* **Interactive Exploration:** Explore planetary mass, radius, orbital parameters, and host star characteristics dynamically.
